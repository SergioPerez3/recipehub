# 🍳 RecipeHub

Red social de recetas: cada usuario publica sus recetas y puede ver el perfil de otros usuarios.

## Estructura

```
Recipehub/
├── server/   API REST (Node, Express, MongoDB) → ver server/README.md
└── client/   Aplicación React (Vite)
```

## Estado del proyecto

- [x] Back de la V1: registro, login, CRUD de recetas y perfil de usuario
- [x] Tests del back
- [ ] Front de la V1
- [ ] V2: likes, comentarios, guardar recetas, búsqueda y categorías

La documentación de la API está en [`server/README.md`](server/README.md).
